# Function initializeLightSources

* initializeLightSources(group: [EffectsCanvasGroup](../classes/foundry.canvas.groups.EffectsCanvasGroup.md)): void

  A hook event that fires during light source initialization.
  This hook can be used to add programmatic light sources to the Scene.

  #### Parameters

  + group: [EffectsCanvasGroup](../classes/foundry.canvas.groups.EffectsCanvasGroup.md)

    The EffectsCanvasGroup where light sources are initialized
