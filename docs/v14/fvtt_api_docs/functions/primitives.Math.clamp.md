# Function clamp

* clamp(num: number, min: number, max: number): number

  Bound a number between some minimum and maximum value, inclusively.

  #### Parameters

  + num: number

    The current value
  + min: number

    The minimum allowed value
  + max: number

    The maximum allowed value

  #### Returns number

  The clamped number
