# Function isSubclass

* isSubclass(cls: Function, parent: Function): boolean

  Test whether some class is a subclass of a parent.
  Returns true if the classes are identical.

  #### Parameters

  + cls: Function

    The class to test
  + parent: Function

    Some other class which may be a parent

  #### Returns boolean

  Is the class a subclass of the parent?
