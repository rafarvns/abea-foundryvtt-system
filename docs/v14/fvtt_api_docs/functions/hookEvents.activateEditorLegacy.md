# Function activateEditorLegacy

* activateEditorLegacy(editor: any, options: object, initialContent: string): void

  A hook event that fires when the button to activate an editor is pressed. This hook will be removed when
  ApplicationV1 completes its deprecation period in v16.

  #### Parameters

  + editor: any

    The editor instance.
  + options: object

    Options to configure activation.
  + initialContent: string

    The initial editor content.

  #### Returns void

  #### Deprecated

  since v14 until v16
