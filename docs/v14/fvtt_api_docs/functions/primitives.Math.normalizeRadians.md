# Function normalizeRadians

* normalizeRadians(radians: number): number

  Transform an angle in radians to be bounded within the domain [-PI, PI]

  #### Parameters

  + radians: number

    An angle in degrees

  #### Returns number

  The same angle on the range [-PI, PI]
